This folder contains FAISS index files built by:
  python scripts/build_index_v2.py

  index_theory_meta.json
  index_calculations.faiss    - Calculation/formula chunks
  index_calculations_meta.json
  index_qa.faiss              - Exam questions/answer schemes
  index_qa_meta.json

IMPORTANT: Commit these files to GitHub before deploying to Render.
