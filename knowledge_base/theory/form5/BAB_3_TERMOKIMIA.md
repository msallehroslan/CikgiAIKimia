# 3.1 Perubahan haba dalam tindak balas

## Tindak Balas Eksotermik & Endotermik

Terdapat perubahan tenaga apabila tindak balas kimia berlaku.

Apabila tindak balas kimia berlaku:
- Tenaga haba dibebaskan atau
- Tenaga haba diserap

Tindak balas kimia boleh dibahagikan kepada dua jenis:

1. Tindak balas eksotermik
2. Tindak balas endotermik

---

## Rajah Aras Tenaga

![Rajah Aras Tenaga Eksotermik & Endotermik](images/bab3_rajah_aras_tenaga.png)

Rajah aras tenaga menunjukkan:
- Perbezaan kandungan tenaga bahan tindak balas
- Kandungan tenaga hasil tindak balas

---

### Tindak Balas Eksotermik

Ciri-ciri:
- Tenaga haba dibebaskan
- Tenaga hasil tindak balas lebih rendah
- ΔH bernilai negatif

Contoh:
- Pembakaran bahan api
- Penetralan asid dan alkali

---

### Tindak Balas Endotermik

Ciri-ciri:
- Tenaga haba diserap
- Tenaga hasil tindak balas lebih tinggi
- ΔH bernilai positif

Contoh:
- Fotosintesis
- Penguraian haba

---

## Persamaan Termokimia

Persamaan termokimia menunjukkan perubahan haba bagi sesuatu tindak balas.

Contoh tindak balas eksotermik:

Mg(s) + H₂SO₄(aq) → MgSO₄(aq) + H₂(g)  
ΔH = –467 kJ mol⁻¹

# 3.2 Haba Tindak Balas

Haba tindak balas ialah perubahan haba yang berlaku semasa sesuatu tindak balas kimia.

Jenis haba tindak balas:

1. Haba pemendakan
2. Haba penyesaran
3. Haba peneutralan
4. Haba pembakaran

---

## Penentuan Haba Tindak Balas

Haba tindak balas boleh ditentukan melalui eksperimen.

---

## Rajah Susunan Eksperimen Kalorimeter

![Rajah Kalorimeter](images/bab3_kalorimeter.png)

Langkah pengiraan haba:

1. Tentukan perubahan suhu
2. Hitung haba yang dibebaskan atau diserap
3. Gunakan formula pengiraan haba

---

## Formula Haba

Q = mcΔT

di mana:

Q = haba  
m = jisim bahan  
c = muatan haba tentu  
ΔT = perubahan suhu

---

# Haba Pemendakan

Haba pemendakan ialah perubahan haba apabila **1 mol mendakan terbentuk daripada ion dalam larutan akueus.**

Contoh:

Ba²⁺(aq) + SO₄²⁻(aq) → BaSO₄(s)  
ΔH = –42 kJ mol⁻¹

---

# Haba Penyesaran

Haba penyesaran ialah perubahan haba apabila **1 mol ion logam disesarkan oleh logam yang lebih elektropositif.**

Contoh:

Fe(s) + Cu²⁺(aq) → Fe²⁺(aq) + Cu(s)

# Haba Peneutralan

Tindak balas peneutralan berlaku antara:

- Asid
- Alkali

dan menghasilkan:

- garam
- air

Persamaan ion:

H⁺(aq) + OH⁻(aq) → H₂O(l)

---

## Rajah Eksperimen Peneutralan

![Rajah Peneutralan](images/bab3_peneutralan.png)

---

Haba peneutralan ialah perubahan haba apabila **1 mol air terbentuk daripada tindak balas peneutralan.**

Contoh:

HCl(aq) + NaOH(aq) → NaCl(aq) + H₂O(l)  
ΔH = –57 kJ mol⁻¹

---

# Haba Pembakaran

Haba pembakaran ialah perubahan haba apabila **1 mol bahan dibakar sepenuhnya dalam oksigen.**

Contoh:

CH₄(g) + 2O₂(g) → CO₂(g) + 2H₂O(l)  
ΔH = –394 kJ mol⁻¹

---

# Nilai Bahan Api

Nilai bahan api ialah kuantiti tenaga yang dibebaskan apabila **1 g bahan api dibakar sepenuhnya dalam oksigen.**

Unit:

kJ g⁻¹

# 3.3 Aplikasi Tindak Balas Eksotermik & Endotermik dalam Kehidupan Harian

Penemuan api merupakan salah satu penemuan penting dalam sejarah manusia.

Tenaga haba daripada pembakaran digunakan untuk:

- memasak makanan
- menghasilkan tenaga
- menghasilkan cahaya
- menggerakkan mesin

---

## Nilai Bahan Api

Setiap bahan api mempunyai nilai haba pembakaran yang berbeza.

Nilai bahan api bergantung kepada:

- jenis bahan api
- bilangan atom karbon
- struktur molekul

Bahan api dengan nilai haba tinggi lebih sesuai digunakan sebagai sumber tenaga.
